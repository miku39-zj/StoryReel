# 画布生成与分支调试

## 创作闭环

- 文本、图片、视频之间的素材连线决定生成输入；剧情连线决定播放顺序，两者互不替代。
- 点击图片或视频生成会根据素材依赖排序，先生成缺失或过期的上游素材，再生成目标节点。当前实现按顺序执行，失败会阻止依赖任务。
- 编辑提示词、角色故事设定、相关剧情路线或参考素材后，节点显示“素材过期”。左侧“生成任务”可以重新生成过期素材。
- AI 输入包含已有故事设定、标注了路线的前置剧情和显式连接的参考素材。分支前置内容不会被描述为唯一已发生历史。共享参考图仍需用户显式连接；模型输出的角色一致性不能仅凭上下文保证。
- 每次完成结果保存在节点历史版本中。输入已改变或用户已更换素材时，迟到的结果只进入历史，不覆盖当前选择。可在节点详情选择版本。
- 发布前检查会阻止过期视频、缺失素材、不完整条件以及无法到达结局的路线。

## 持久化任务

任务存在应用 SQLite 的 `canvas_jobs` 表；图片与视频文件沿用 `/api/media/:id` 存储。任务提交使用请求键去重，运行任务使用租约避免网页与 worker 重复执行。外部请求 ID 在提交完成后保存，进程重启后继续查询原任务。

本地查看画布时浏览器会推进队列。生产环境以及关闭网页后继续生成，需要和 Web 服务一起运行现有后台进程：

```sh
npm run worker
```

Web 和 worker 必须使用相同的 `STORYREEL_DATA_DIR` 与 `FAL_API_KEY`。图片沿用 Flux Schnell，视频沿用 Seedance 请求适配器。未配置服务时明确报错，不生成假素材。

如果进程在外部提交完成、保存请求 ID 之前中断，系统无法确认外部是否已经计费；租约到期后将任务标记失败，不自动重提。取消会停止应用结果并尽力请求外部取消，已经执行的生成可能仍计费。重新提交会建立新的任务。

## 变量与条件

项目先声明数字、字符串、布尔变量。路线支持原有赋值，以及按顺序执行的赋值、数字增加/减少、布尔取反。类型不匹配会报错，不隐式转换。

条件节点可配置多个比较条件，选择全部满足（AND）或任一满足（OR）；保留 true / false 两个出口。旧项目的单条件格式仍兼容。自动跳转失败会回滚本次变量和调试记录。

“分支调试”不调用模型、不播放视频，也不修改项目变量。可指定测试初始变量，逐步选择路线，查看变量与条件判断记录。修改画布后需重新开始调试以取得新快照。预览面板也显示实际播放的变量和判断记录。

## 验证边界

自动测试使用临时数据库和模拟服务响应，覆盖任务重启恢复、去重、取消依赖、未知提交状态、素材输入、过期传播、版本保护、变量运算和公开播放快照。真实模型质量与实际计费没有在测试中调用。

## 画布编辑与参考绑定

画布工具支持框选、多选复制粘贴、自动布局、搜索定位和命名分组。命名分组是节点标签，并非嵌套容器；复制仅保留选中节点之间的内部连线，不复制运行中的任务身份。分组不会使已有素材过期。

图片节点可标记为角色参考或场景参考并填写固定设定。视频节点可直接绑定这些参考，建立真实素材连线；参考设定和图片变化会使下游素材过期。首尾帧与参考图的组合仍受现有生成接口约束。

本地剧情检查提示重复选项、没有实际差异的分支及空结局，不调用模型，也不替代人工剧情审阅。

## 提交确认与任务控制

生成前先显示完整依赖清单、图片和视频数量，确认后才入队。确认时会检查输入是否变化。默认单批最多 12 项、全局同时排队或运行最多 24 项，可通过 `STORYREEL_MAX_BATCH` 和 `STORYREEL_MAX_ACTIVE` 调整（最大 100）。

仅在配置 `STORYREEL_IMAGE_ESTIMATE_CNY`、`STORYREEL_VIDEO_ESTIMATE_CNY` 后展示对应估算；缺少必要单价时明确显示未知。估算不等于供应商实际账单。

任务面板显示后台在线状态；无在线后台时由当前页面推进。失败任务若保留外部任务 ID，可恢复查询原任务而不重新提交。后台进程仍需单独部署，健康状态不代表已安装自动启动服务。

## 项目历史

保存时保留最近 50 个旧版本。历史面板支持查看和恢复，恢复会产生新版本并保留恢复前的内容。恢复前先保存当前编辑，使用版本检查避免覆盖冲突；存在排队或运行任务时必须等待或取消后恢复。已发布快照不随恢复改变。

## 共享任务治理与编辑访问

画布队列和逐镜队列共用单批新增任务上限与全局活动任务上限。额度检查和任务写入处于同一数据库写事务；重复请求或复用已有任务不会重复占用额度。历史恢复同样检查两套队列，恢复的是项目草稿，不删除或回滚素材生产历史。

删除项目会在同一事务中停止两套队列并记录删除标记，旧缓存不能重新提交生成或覆盖恢复该项目；需要保留内容时应另存为新项目。已发送给外部供应商的请求可能仍会计费，但迟到结果不再回填已删除项目。

当前访问控制面向单个共享工作区，并非多租户账号系统。在生产环境必须同时配置 `STORYREEL_EDITOR_USER` 和 `STORYREEL_EDITOR_PASSWORD`；缺少配置时编辑入口拒绝访问。编辑端使用浏览器 HTTP Basic 凭据，对外部署必须使用 HTTPS。开发命令默认只监听 127.0.0.1；如需对外提供开发服务，同样应配置凭据。

公开作品页和发布快照可匿名读取；媒体只有被当前发布快照引用时才允许匿名访问，其他媒体需要编辑凭据并使用私有缓存策略。撤销发布不会清除观众此前已经缓存或下载的文件。

项目更新需携带预期 revision 或 If-Match。集合接口省略版本只允许创建新项目；单项目 PUT 缺少预期版本返回 428，版本冲突返回 409。

### 分支连续路线

AI 分支方案中没有决策点或结局的场景，优先沿用原剧本唯一一条 `choices[].leadsTo` 自动继续；只有未定义唯一后继时，才兼容旧项目按场景顺序继续。两条互斥路线不能因为列表相邻就串到一起。

`lib/story/branch-routes.ts` 统一解析这些后继并校验引用、可达性与结局，服务端分支校验和画布回填共同使用。`lib/ai/creation-response.ts` 负责分支、分镜前端响应的完整 UTF-8 解码和错误读取，业务模块各自负责结构校验与应用。分镜页面会显示服务端具体校验错误，失败时保留原有分镜数据。

## 角色参考与首尾帧

应用新故事时，角色资料会初始化为 `assetKind:character` 的独立图片节点。旧项目可在创作步骤“角色与画面”点击“从剧本建立角色卡”；不会覆盖已有角色图。固定设定、图片版本与生成任务直接复用画布节点和账本，不维护第二份角色素材状态。

选定角色图后，为每个场景选择出镜角色并创建两个独立首尾帧图片节点。实际连接为：`角色图 + 文本 → 镜头图片 → 视频首帧/尾帧`。图片节点的输入只允许文本提示词与参考图；首尾帧用途属于视频输入边。修改参考图片或设定会沿输入依赖提示下游过期，不直接覆盖成片。

OpenAI 兼容图片服务有参考输入时使用 `/images/edits` JSON `images:[{image_url:...}]`，无参考输入时仍使用 `/images/generations`。本地素材解析为 Data URL，复用服务端媒体读取逻辑。网关的完整编辑地址可通过 `IMAGE_EDIT_BASE_URL` 覆盖。接口失败不会回退到纯文生图；未声明参考图片协议的 fal 模型会明确拒绝，不静默丢弃参考。

逐镜生产也通过 `productionShots` 解析场景首尾帧所绑定的角色图。任务快照保存参考地址与角色修订，图片生成使用同一编辑适配器；角色图或固定设定改变后，逐镜页和应用校验使用相同修订计算，旧素材不会被当作当前版本。未生成角色图时会提示先完成角色。

## 分集、镜头与播放路线

剧本场景可以填写集号。旧场景默认属于第 1 集。多集连续剧可在逐镜生成页筛选集数，在成片页按集导出 MP4。互动剧在剧本阶段设计分支，选项的目标使用具体场景 ID，同一集的多个分支可分别制作和预览。

从逐镜生成页打开镜头画布，或双击剧情路线的播放片段进入对应镜头。镜头画布展示当前镜头及其素材依赖。剧情路线折叠片段内自动连接的镜头链，保留选择、条件、汇合、结局和跨片段连接。切换视图不会中断生成任务。

需要接拍时，在镜头画布的「镜头承接」中选定前置播放镜头，截取所选视频版本的实际出点并接入首帧。前置视频、出点或路由变化后需重新复核。切景时可恢复独立首帧。首尾帧用于固定边界画面，中间关键画面可接到多素材参考模式。
