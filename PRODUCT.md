# Product

## Register

product

## Users

Chinese-speaking creators build interactive dramas, scripts and branching stories in a desktop creative workspace. They need to move quickly between an idea, a structured script, visual assets, a canvas and playback.

## Product Purpose

StoryReel turns story ideas into editable interactive projects. The dashboard starts or reopens projects; the creation workflow guides authors through six production steps.

## Brand Personality

Focused, cinematic, approachable. Current layout uses a glacier blue theme. Narrow icon rail, centered creation heading, attached mode tabs and composer, original projector mascot, four compact shortcuts and a 2:1:1 inspiration gallery. Dark blue surfaces and icy cyan accents; retain dotted particles with pointer-following local illumination. Use subtle dotted texture, compact controls and minimal copy. On narrow screens collapse sidebar labels and wrap tools into two columns. Preserve existing project data and creation handlers.

## Design Principles

- Keep the story and the next action easy to find.
- Use shared library components for consistent interaction and sizing.
- Let content determine card height; never clip labels to fit a button.
- Keep navigation predictable and adapt the workspace to narrower screens.

## Accessibility & Inclusion

Provide visible keyboard focus, accessible names for icon actions and selected states. Respect reduced motion and allow readable wrapping.
